# Start here

Orientation for a new student technician: what the team supports, how a
shift runs, and the order to read the rest of this site in.

Follow the [onboarding path](onboarding.md): four stages, from learning
the rooms and shadowing to taking calls alone, the first runbooks to
learn, and what the shift lead checks before signing you off.

In short, read the rest of the site in this order:

1. [Rooms](../rooms/index.md), to see what equipment a classroom has.
2. [Runbooks](../runbooks/index.md), starting with the first runbooks the
   onboarding path lists.
3. [Procedures](../procedures/index.md), for when to hand a problem on and
   how a shift hands over to the next.
