# Reference

The ServiceNow knowledge-base export format, and how this site's categories
map to the knowledge base's taxonomy.

- [Knowledge-base export format](kb-export-format.md): what is exported,
  the command, the XML file's records and fields, how links and anchors are
  carried over, and what is left out.
- [Taxonomy mapping](taxonomy-mapping.md): the knowledge-base category for
  each section, the workflow state for each status, and where identifiers,
  titles and equipment go.

The export is generated from the runbooks themselves, so the knowledge base
and this site cannot drift apart.
