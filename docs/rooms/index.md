# Rooms

The room inventory: each building's rooms and each room's equipment,
linked to the runbooks for that equipment.

The inventory is to come. It will be kept as data and turned into one page
per building, so that a room's page and the coverage check read the same
source. Every piece of equipment in a room will link to the runbooks in
[Runbooks](../runbooks/index.md) that cover it.

The rooms are illustrative, not a real campus's inventory.
